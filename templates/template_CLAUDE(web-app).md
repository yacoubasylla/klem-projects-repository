# Context: Front-End React
- **Stack :** React, TypeScript, Material UI, TanStack Query (pour le cache API).
- **Standards :**
    - Design : Utiliser exclusivement les composants de `@klem/ui`.
    - État : Zustand pour l'état global, React Query pour les données serveur.
    - Performance : Lazy Loading des routes et composants lourds.
- **Spécificité :** Accessibilité (A11y) et réactivité mobile (Responsive).
