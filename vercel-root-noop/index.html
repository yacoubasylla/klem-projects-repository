Ce projet Vercel (racine du monorepo klem-projects-repository) ne sert intentionnellement aucune application.

Chaque application déployable a son propre projet Vercel dédié avec son Root Directory propre : cantine-connect (rootDirectory apps/web-app/cantine-connect/client-frontend), klem-labs-dashboards. Ce projet racine reste rattaché au dépôt uniquement pour afficher un statut de build (ex. checks de Pull Request) sans jamais être une cible de déploiement réelle — voir vercel.json et l'ADR associé dans collaboration/history/adr/.
